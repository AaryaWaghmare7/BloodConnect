# 🩸 BloodConnect

### Connecting Donors. Saving Lives.

**BloodConnect** is a web-based Blood Donation and Management System developed to simplify the process of connecting potential blood donors with individuals and organisations seeking blood.

The platform aims to make donor discovery, blood requests, and blood bank information more accessible through a centralised, user-friendly interface.

## Project Overview

BloodConnect provides a digital platform where users can register as blood donors, search for donors by blood group and location, submit blood requests, and explore blood banks and donation camps.

The project combines a modern web interface with Java-based application logic and a relational database management system.

## Key Features

- **Donor Registration:** Register and manage donor profiles.
- **Find Donors:** Search donors based on blood group, city, and availability.
- **Blood Requests:** Submit and track blood requirements.
- **Blood Bank Directory:** Explore blood bank information.
- **Donation Camps:** Discover upcoming blood donation events.
- **User Dashboard:** Manage personal profiles and requests.
- **Admin Dashboard:** Manage donor, request, and platform records.

## Database Management System

BloodConnect is designed to demonstrate practical DBMS concepts, including:

- Relational database design and ER modelling
- DDL and DML operations
- Primary keys, foreign keys, and constraints
- SQL operators, functions, joins, and subqueries
- Views, indexing, and aggregation
- Transactions and database administration
- Stored procedures, triggers, and cursors

## Project Architecture

**React Frontend → Java Backend → MySQL Database**

The frontend provides the user interface, the Java backend will handle application logic and database communication, and MySQL will manage persistent data storage.

## Project Status

**Under Development**

The React frontend is being developed with demonstration data. Java backend integration and MySQL-powered functionality are planned for subsequent development stages.

## Project Vision

BloodConnect aims to demonstrate how Java programming, database management, and modern web technologies can work together to build an accessible and socially meaningful application.

*BloodConnect is an educational project, not an emergency medical service. Donor eligibility, blood compatibility, and availability must be confirmed by qualified healthcare professionals.*
